# Skills

Reusable skill instructions for ChatGPT and Codex.

- [Job Hunter](job-hunter/SKILL.md): evidence-based CV tailoring, job discovery, letters, application tracking and interview preparation.
- [Investment Tracker](investment-tracker/SKILL.md): S&P 500 pre-market screening, growth comparisons and research into price movements.

- [Six Player Generator](six-player-generator/SKILL.md): Amazon-style product strategy six-pagers, with an [Apple Watch worked example](six-player-generator/apple-watch-six-pager-october-2026.md).

For a local skill-capable environment, copy the desired folder into its configured skills directory. In ChatGPT, provide the skill instructions in your chat or project context. This repository contains skill sources, not an installed plugin; browsing and other capabilities depend on the host.

Keep personal profiles, application records and financial account information outside this repository. Job Hunter's licence and upstream attribution are retained in its folder. Investment Tracker is adapted from the Pre-Market Growth Screener instructions.
